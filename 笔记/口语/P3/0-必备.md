#### 一、万能逻辑模板（所有P3问题通用）

P3问题通常就是五类，记住这个表就够了：

|问题类型|常见问法|万能回答结构|
|---|---|---|
|**原因类**|Why...? / What causes...?|I think it's mainly because... / This is due to... / The main reason is...|
|**影响类**|What are the effects of...?|It can lead to... / This causes... / One major impact is...|
|**对比类**|How is A different from B?|Well, A is..., while B is... / The main difference is... / Unlike A, B...|
|**解决类**|How to solve...? / What should be done?|The government should... / Individuals can... / Both sides need to...|
|**预测类**|Will this trend continue?|I think it will... because... / It's hard to say, but probably...|

#### 四、最后一天的急救复习策略

只剩一天，不要背太多新词。**按这个顺序做**：

1. **早晨（30分钟）**：把上面10组核心语料背下来，大声朗读3遍。
    
2. **上午（1小时）**：拿3道P3真题，每个问题用“万能逻辑模板”+“核心语料”说2分钟，录下来自己听。
    
3. **下午（1小时）**：重点背“万能开头模板”和“好句”，确保到考场上不会冷场。
    
4. **晚上（30分钟）**：把上面的短语全部过一遍，只看中文说英文，卡住的标记出来再背一遍。
    

**考场上记住这句话：**

> _考官问什么不重要，你永远可以往“科技/压力/政府责任/健康”这四个方向引。_

比如考官问“为什么年轻人喜欢网购？”你可以说：

> _Well, I think the main reason is that... businesses use advertisements to encourage people to spend more money, and many young people shop just for fun instead of real demand. Besides, scrolling through social media for a long time exposes them to endless ads, so they can't help buying things._

一句话里用上3个核心语料，考官就觉得你很有内容。
